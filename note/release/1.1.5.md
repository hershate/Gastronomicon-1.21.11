# 1.1.5 — 修复加载期崩溃 + 移除匿名上报/更新检查

> 基于 `fix/remove-guizhanlib-runtime-dep`（自 `adapt/build-1.21.11` 切出），在 1.1.4 基础上的**关键修复**版本。
> 目标：修复在部分服务端（如 [Papo](https://github.com/hershate/Papo)）上插件无法加载的严重错误。

## 问题

启用时报：

```
java.lang.NoClassDefFoundError: net/guizhanss/guizhanlib/slimefun/addon/Scheduler
    at ...Gastronomicon.enable(Gastronomicon.java:50)
Caused by: java.lang.ClassNotFoundException: net.guizhanss.guizhanlib.slimefun.addon.Scheduler
```

## 根因

1. **运行期依赖鬼斩前置库（GuizhanLibPlugin），但其包路径随版本迁移**。本插件编译期所依赖的
   GuizhanLibPlugin `2.3.0` 是一个**过渡版本**，同时保留旧路径（`net.guizhanss.guizhanlib.*`，本插件
   所引用）与新路径（`net.guizhanss.guizhanlibplugin.*` / `...gugu...`）。服务器实际安装的版本若已移除
   `slimefun.addon` 模块（含 `Scheduler`），则运行期找不到该类。参考：
   - [guizhanlib-slimefun](https://mvnrepository.com/artifact/net.guizhanss/guizhanlib-slimefun)（含 Scheduler 的模块）已冻结于 2.2.0；
   - [GuizhanLibPlugin 构建页](https://builds.guizhanss.com/ybw0014/GuizhanLibPlugin)。
2. **加载顺序缺陷**：`new Scheduler(this)`（旧 [Gastronomicon.enable](../../src/main/java/io/github/schntgaispock/gastronomicon/Gastronomicon.java) 第 50 行）在「鬼斩前置库存在性检查」**之前**执行，
   因此即便后续有缺失检测，也已先抛 `NoClassDefFoundError`，无法优雅降级。

## 修复：彻底移除 GuizhanLibPlugin 运行期依赖

鬼斩前置库在本插件中的实际使用面极小（仅 4 处），均可内联等价实现，使插件**自包含、与服务器鬼斩前置库版本无关**：

| 原鬼斩前置库 API | 替换为 | 说明 |
|---|---|---|
| `Scheduler.run(Runnable)` | `Bukkit.getScheduler().runTask(plugin, r)` | 反编译确认两者**完全等价**（同步、下一 tick）；见 [TreeGrowthListener](../../src/main/java/io/github/schntgaispock/gastronomicon/core/listeners/TreeGrowthListener.java) |
| `GuizhanUpdater.start(...)` | （移除） | 仅 `Build` 版本才会触发；release 1.1.x 从不执行。其类路径同样版本敏感，一并移除以彻底解除依赖 |
| `ItemStackHelper.getName(item)` | `ItemUtil.getDisplayName(item)` | 新增方法：自定义名 →（SF 物品自带名）→ 材质名人类可读化；见 [ItemUtil](../../src/main/java/io/github/schntgaispock/gastronomicon/util/item/ItemUtil.java) |
| `PotionEffectTypeHelper.getName(type)` | `ItemUtil.getPotionName(type)` | 复用既有方法；见 [FoodEffect](../../src/main/java/io/github/schntgaispock/gastronomicon/api/food/FoodEffect.java) |

配套改动：
- [Gastronomicon.java](../../src/main/java/io/github/schntgaispock/gastronomicon/Gastronomicon.java)：移除 `scheduler` 字段/构造、鬼斩前置库硬依赖检查、自动更新块、相关 import。
- [pom.xml](../../pom.xml)：移除 `net.guizhanss:GuizhanLibPlugin` 依赖；版本 `1.1.4 → 1.1.5`。
- [plugin.yml](../../src/main/resources/plugin.yml)：`softdepend` 移除 `GuizhanLibPlugin`。

## 行为差异（兼容性说明）

- **加载**：不再依赖服务器安装任何特定版本的 GuizhanLibPlugin。`NoClassDefFoundError` 不可能再发生。
- **本地化回退**：移除鬼斩前置库后，对**未命名的纯原版材质** `giveItem` 效果描述（如「获得 1x ...」）
  与**药水效果名**退化为英文/人类可读名（原由鬼斩前置库提供服务端中文名）。影响范围小：
  - Slimefun 物品与任何带自定义名的物品**不受影响**（直接取其显示名）。
  - 仅「给原版材质」类 FoodEffect 的描述文本语言变化；功能完全正常。
- **自动更新**：移除。`options.auto-update` 配置项变为无效（保留以防破坏既有 config）。如需恢复自动更新，
  需在确定服务器鬼斩前置库版本后另行接入对应包路径的 updater。

## 附带：移除匿名上报与更新检查（应后续要求）

- **匿名上报**：删除 bStats `Metrics`（id 16941）与 `SimplePie`；[pom.xml](../../pom.xml) 移除 `bstats-bukkit` 依赖与 `org.bstats` shade 重定向；shaded jar 审计 `bstats` 条目 = **0**。
- **更新检查**：本插件自带 `GuizhanUpdater` 已随上文移除；InfinityLib `AbstractAddon` 的 `GitHubBuildsUpdater` 反编译确认仅对 `"Build \d+"` 版本实例化，release `1.1.5` 不匹配 → `updater=null` → `onEnable` 两处 `start()` 均被 `ifnull` 跳过，故 release 永不联网检查更新；[config.yml](../../src/main/resources/config.yml) `options.auto-update` 置 `false`（键为前置校验所需，保留但恒 false）双保险。
- **README**：移除指向构建站的徽章。
- 完整依赖审计见 [dependency-audit.md](../dependency-audit.md)。

- 全源码审计：除说明性注释外，无任何 `net.guizhanss`/`GuizhanLib`/`org.bstats`/`Metrics` API 调用残留。
